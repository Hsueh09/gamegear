
# GameGear｜電競周邊購物網站

GameGear 是一個以電競周邊商品為主題的購物網站，使用 Next.js、React、TypeScript 與 Tailwind CSS 開發。透過這個專案練習前端網頁開發、元件拆分、動態路由、狀態管理與購物車功能。

## 專案展示

- GitHub Repository：[GameGear](https://github.com/Hsueh09/gamegear)

> 專案畫面截圖將於後續補上。

## 功能介紹

- **首頁商品展示**：展示商品資訊與自動輪播商品。
- **商品列表**：瀏覽電競周邊商品。
- **商品詳細頁**：查看商品圖片、價格與商品描述。
- **商品數量選擇**：選擇加入購物車的商品數量。
- **購物車管理**：加入商品、修改數量、刪除商品。
- **金額計算**：自動計算商品小計與購物車總金額。
- **購物車數量顯示**：在共用導覽列顯示購物車商品數量。

## 本機執行方式

### 環境需求

請先安裝 Node.js 與 npm。

### 安裝與啟動

```bash
git clone https://github.com/Hsueh09/gamegear.git
cd gamegear
npm install
npm run dev
```

開啟瀏覽器並前往：

http://localhost:3000

## 專案學習重點

- 使用 React 元件拆分頁面與重複 UI。
- 使用 TypeScript 定義商品資料型別。
- 使用 Next.js 動態路由呈現商品詳細頁。
- 使用 `map()` 與 `find()` 處理商品資料。
- 使用 React Context API 管理購物車狀態。
- 使用 Tailwind CSS 建立一致的黑白灰視覺風格。
